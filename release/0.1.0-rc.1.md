# Vesta GPUI 0.1.0 candidate 1

Status: local source candidate, not a final release or registry publication.

This candidate starts independent maintenance of the existing eight-library
Rust UI family, with Standalone and Motion examples. It provides declarative
elements, shared layout/text/input and control state, native winit/Vulkan host
integration, accessibility projections and opt-in structured UI observation and
controlled actions for authorized Agent integrations.

This maintenance epoch cleans private repository context links and checkout
paths, preserves the Apache-2.0 license and embedded font attribution, and replaces
the product exporter with a repository-local source seal and packaging procedure.
It makes no Rust, shader, dependency, widget behavior or API changes to the
imported candidate. Exact import and source identities are in `IMPORT.json` and
`SOURCE.json`.

The supported baseline is Windows x86-64, Rust 1.89.0 / Edition 2024. Host fonts
and a Vulkan runtime are required for native rendering. Workspace/floating
windows, WebView2 and the optional viewport retain their documented limits.
Browser/WASM execution, full editor authoring, unrestricted OS automation and
unloaded virtual content are outside this release. AccessKit projections do not
promise complete platform TextRange or reader behavior.

See [Agent access](../docs/AGENT-ACCESS.md), the per-package supported API
inventories, [validation scope](../docs/VALIDATION.md) and
[release commands](../docs/RELEASING.md). Actual new qualification results are
distributed as a sidecar; historical product results are not re-labelled as new
independent runs. Public repository creation, an immutable commit/tag and Vesta
consumer migration are still pending.
